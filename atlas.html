Atlas, the database engine for Lunaris

A minimal, PDO-based data layer that keeps raw SQL in your hands — with an optional query builder, Active Record models and DTO hydration when you want them. The package is being rebuilt from scratch and its public API is not final yet.

Planned API

What Atlas will bring

A preview of the documented direction. Names and behaviour may change before the first stable release.

🗄️

Raw SQL first

Atlas::prepare(...)->args([...])->execute() with prepared statements, named parameters and a rich result set.

🔍

Probe query builder

A fluent builder for select, insert, update and delete — where, orWhere, whereIn, joins, order, limit and offset.

🪐

Planet models

Active Record with $table, $fillable, $hidden and $casts — find(), where(), save(), delete().

💊

Capsule DTOs

Hydrate rows into typed objects with casting for int, float, bool, JSON, DateTime and more.

♻️

Query objects

Reusable, testable SQL classes: extend Query, implement sql(), run it with Atlas::run().

🔒

Transactions & drivers

Closure-based transactions, insert-ID metadata, JSON-ready results — targeting MySQL, PostgreSQL and SQLite.

Status

Atlas is at an early stage: the source tree has been reset and is being rewritten. Nothing on this page is a commitment — treat it as a roadmap. Documentation for Atlas will land here once the package stabilises.
